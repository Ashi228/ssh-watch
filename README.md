# SSH Watch

Учебный проект для SOC. Скрипт на Python читает экспорт журнала OpenSSH в формате JSONL, считает неудачные входы по паре «пользователь + IP» и показывает время события, имя пользователя и адрес источника.

## Запуск

Откройте терминал в папке проекта и выполните `python ssh_watch.py` (Windows) или `python3 ssh_watch.py` (Linux). Достаточно Python 3. Тестовый журнал `ssh-events.jsonl` содержит вымышленные записи.

В последнем событии пользователь `demo` успешно входит с `192.0.2.24`. Скрипт помечает этот вход как `[ALERT]` и показывает две предыдущие неудачные попытки. Ошибки другого пользователя с того же адреса и того же пользователя с другого адреса учитываются отдельно.

## Как работает правило

При двух или более неудачных попытках для одной пары скрипт помечает следующие события этой пары как `[ALERT]`. Счётчик ведётся по всему файлу без ограничения по времени. Повторные ошибки и последующий вход дают повод проверить событие вручную.

Скрипт рассчитан на записи `Accepted password for … from …` и `Failed password for … from …` с полями `MESSAGE` и `SYSLOG_TIMESTAMP`. Формат `Failed password for invalid user …` требует отдельной обработки.
